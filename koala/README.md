# أحلام الكوالا مسؤوليتنا

لعبة صفية عربية إيجابية، مبنية على النموذج المرفق `koala_dreams_v2.html`. الكود الأصلي محفوظ دون تعديل في `prototype.html` للمقارنة. اللعبة الجديدة في `index.html`، ولا تغيّر موقع Captivate الموجود في جذر المستودع.

**بهدوئنا نحافظ على أحلامه… وبمسؤوليتنا نصنع الفرق**

## اللعب من المتصفح دون تثبيت

رابط GitHub Pages: **https://fedia12.github.io/fayeb.github.io/koala/**

افتحي الرابط مباشرة في متصفح حديث، ثم اختاري «ابدئي رحلة الأحلام». يمكن استخدام «التجربة دون ميكروفون» دون منح أي إذن. للقياس الحقيقي اسمحي بالميكروفون عند الطلب. لا يلزم تنزيل ملفات أو تثبيت Python أو أي برنامج على جهاز المعلمة؛ تعليمات الخادم المحلي أدناه للمطوّرات فقط.

أكد سجل GitHub نجاح نشر الإصدار `98c72788989ecc2d0db465a7e8e02bb3d1763ab3` في [تشغيل Pages رقم 38869006475](https://github.com/fedia12/fayeb.github.io/actions/runs/38869006475). اللعبة في مجلدها `/koala/` والموقع القديم في الجذر لم يتغير. في إعادة الاختبار بتاريخ ١٧ أكتوبر ٢٠٢٦ نجحت اختبارات Chromium المحلية، لكن سياسة شبكة بيئة الاختبار منعت الوصول إلى نطاق Pages؛ لذلك لم يُتحقق بعد من تفاعل الصفحة المنشورة أو الميكروفون على عنوان HTTPS العام. نجاح النشر لا يغني عن اختبار الصفحة الحية.

## التشغيل

يتطلب التشغيل متصفحًا حديثًا. لا توجد حزم JavaScript أو خطوة بناء أو مفاتيح API.

```sh
cd /workspace/fayeb.github.io/koala
python3 -m http.server 8080 --bind 127.0.0.1
```

افتحي المنفذ المحلي 8080 على جهازك. لا تفتحي الملف مباشرة عبر `file://`، لأن JavaScript يستخدم modules والميكروفون يحتاج سياقًا آمنًا. عند التشغيل خارج الجهاز المحلي يلزم HTTPS. في البيئة السحابية يمكن فحصه بطلبات محلية؛ لا يفترض هذا الدليل وجود خدمة معاينة عامة.

اضغطي «ابدئي رحلة الأحلام» لاختيار الإعدادات. يمكن التجربة دون منح إذن الميكروفون. تختفي نافذة المعلمة عند البدء. فتح الإعدادات أثناء التحدي يوقفه ويعيد ضبطه؛ زر الإيقاف المؤقت يحافظ على الوقت والنتائج لاستئنافها.

## إعداد الميكروفون في الصف

1. افتحي الموقع عبر HTTPS في Chrome أو Edge أو Firefox أو Safari حديث. افتحيه مباشرة، أو اسمحي بالميكروفون في إعدادات التضمين إن استُخدم داخل iframe.
2. ضعي الميكروفون في موقع ثابت بعيدًا عن مكبرات الصوت والمراوح قدر الإمكان.
3. اختاري نشاط الصف، ثم اضغطي «معايرة الميكروفون». اسمحي بالوصول واتركي ضجيج الغرفة الطبيعي لمدة ٣ ثوانٍ. يُغلق الميكروفون بعد المعايرة.
4. اضبطي الحساسية وعايري مجددًا بعد تغييرها. المعايرة تضيف هامشًا إلى حد النشاط؛ ليست معايرة ديسيبل علمية. تُحفظ المعايرة في ذاكرة الجلسة فقط.
5. ابدئي التحدي، وجربي كلامًا هادئًا ثم صوتًا مستمرًا. ينبغي ألا توقظ نقرة قصيرة الكوالا، بينما يُظهر الصوت المستمر تنبيهًا ثم بكاءً وفق المدة المختارة.
6. اخفضي الصوت للمدة المحددة للتعافي. يمسح الكوالا عينه ثم يعود للنوم، ولا توجد خسارة جماعية أو تقييم فردي.
7. عند رفض الإذن، اسمحي به من إعدادات الموقع ثم حاولي مجددًا، أو اختاري التجربة دون ميكروفون. عند فصل الميكروفون يتوقف التحدي مؤقتًا؛ أعيدي البدء لإعادة التوصيل.

التحليل RMS محلي باستخدام Web Audio و`getUserMedia`، دون `MediaRecorder` أو تسجيل أو حفظ أو إرسال للصوت. المصدر غير موصول بمكبرات الصوت. تُغلق المسارات وAudioContext عند إعادة البدء أو النهاية أو مغادرة الصفحة. لا توجد تحليلات أو مكتبات CDN أو خطوط خارجية.

## طريقة اللعب

- النوم: تنفس لطيف، حركة أذن دورية، ونجوم هادئة؛ لا دموع.
- التنبيه: يبدأ بعد نحو ٠٫٨ ثانية من الضوضاء المستمرة بعد التنعيم.
- البكاء: يبدأ بعد المدة المختارة (٢–٢٠ ثانية). ست قطرات مستقلة بمواعيد ومدد مختلفة تتكوّن وتسقط وتتجدد. لا أصوات بكاء أو أضواء وامضة.
- التعافي: يتطلب انخفاض الصوت تحت ٧٨٪ من العتبة لمدة ٢–٢٠ ثانية، ثم مسح العين والعودة للنوم خلال نحو ٢٫٥ ثانية.
- النهاية: عند انقضاء ١–٣٠ دقيقة، تظهر حالة الفرح والرسالة العربية المطلوبة ونجوم لطيفة ونتيجة تشجيعية، مهما حدث من ضوضاء سابقة.

التنعيم أُسّي، والعتبة المنخفضة للتعافي تمنع التبديل السريع. المؤقّت يخصم الزمن الفعلي دون حدّ الإطار الذي كان يبطئ النموذج الأصلي. عند إخفاء علامة التبويب يتوقف التحدي مؤقتًا صراحةً، ولا يستأنف تلقائيًا. الإطارات المتأخرة أكثر من نصف ثانية لا تُحتسب ضمن الإحصاء الصوتي لأن الصوت خلالها لم يُرصد. نسبة الهدوء هي وقت الهدوء المرصود ÷ الوقت الصوتي المرصود، وليست تقييمًا لكل طالبة. إن لم تتوفر عينات كافية تظهر شرطة بدل نسبة مختلقة.

## الملفات

- `index.html`: واجهة RTL، إعدادات المعلمة، النتيجة، عناصر الوصول.
- `style.css`: التخطيط المتجاوب والحركات والانتقالات والدموع.
- `app.js`: دورة الحياة والميكروفون والمعايرة والعرض التجريبي وملء الشاشة.
- `engine.mjs`: آلة حالات مستقلة قابلة للاختبار.
- `assets/dreams.png`: أربع حالات سينمائية مرسومة للشخصية والغرفة.
- `assets/recovery.png`: مشهد التعافي ومسح العين.
- `assets/arabic-*.ttf`: خطوط Noto Sans Arabic المحلية مع الترخيص في `assets/FONT-LICENSE.txt`.
- `tests/`: اختبارات النموذج والمتصفح والميكروفون الاصطناعي.
- `prototype.html`: النموذج الأصلي المرجعي، وليس إصدار اللعبة الجديد.

## التحسينات مقارنة بالنموذج الأصلي

- استبدال الرسمة الهندسية برسومات مفصّلة ذات مظهر فيلم رسوم متحركة، مع شخصية وردية متناسقة وغرفة شجرة دافئة وإضاءة مختلفة لكل حالة.
- إضافة حالة تعافٍ مستقلة مع وضعية مسح العين، وإعادة الهدوء بسلاسة.
- إصلاح الدموع: فصل اليسار عن اليمين، قطرات متجددة، تأخيرات مختلفة، سقوط واضح وإخفاء كامل خارج البكاء.
- مؤقّت مستقل عن سرعة الإطارات، وتوقف صريح عند إخفاء الصفحة.
- تنعيم RMS، hysteresis، إعادة استخدام مصفوفة العينات، وتنظيف الميكروفون في نهاية الاستخدام.
- إضافة مدة تعافٍ قابلة للضبط، ومعايرة ضجيج الخلفية، ورسائل إذن واضحة دون نوافذ alert مزعجة.
- تطوير العرض التجريبي: هدوء، ضوضاء متزايدة، ضوضاء مستمرة، تعافٍ ونهاية سعيدة باستخدام الحالات الحقيقية نفسها.
- إعادة ضبط العرض التجريبي والميكروفون والأزرار والإحصاء دون بقايا من التحدي السابق.
- إحصاء إيجابي للوقت المرصود، وواجهة عربية متجاوبة مع تنقل بلوحة المفاتيح ودعم تقليل الحركة.

## الاختبارات

اختبارات المحرك لا تحتاج أي حزم:

```sh
node --test tests/engine.test.mjs
```

لتشغيل اختبارات المتصفح، ابدئي الخادم أعلاه، واستخدمي بيئة Python فيها Playwright وChromium. إن لم تتوفرا:

```sh
python3 -m venv /tmp/koala-test-env
/tmp/koala-test-env/bin/pip install playwright
/tmp/koala-test-env/bin/playwright install chromium
```

الاختبارات تستخدم `/usr/bin/chromium` المتاح في بيئة التطوير الحالية. إذا استُخدم متصفح Playwright المثبّت فاحذفي معامل `executable_path` في سكربتي الاختبار أو بدّليه لمسار متصفحك. `--no-sandbox` مخصّص لحاوية الاختبار هنا، وليس مطلوبًا لزائرات الموقع.

```sh
python3 tests/browser_test.py
python3 tests/microphone_test.py
```

الأول يختبر الحالات الخمس، التنفس والأذن، الضوضاء القصيرة، الدموع المتحركة والمستقلة واختفاءها، التعافي، انتهاء دقيقة فعلية بساعة اختبار، الإيقاف والاستئناف، إعادة الضبط، العرض التجريبي، رفض الإذن والتخطيطات بعروض ٣٢٠ و٣٩٠ و٧٦٨ و١٢٠٠ و١٤٤٠ بكسل. الثاني يستخدم **ميكروفون Chromium الاصطناعي** لفحص مسار `getUserMedia` الحقيقي، والمعايرة وRMS وتنظيف المسارات وملء الشاشة. لا يُثبت الاختبار الاصطناعي ملاءمة الحساسية لميكروفون صف حقيقي.

المراجعة اليدوية الموصى بها: شغّلي أوضاع الضوضاء التجريبية بالتتابع، تحققي من تنفس الكوالا وحركة الأذن ودورات سقوط الدموع والانتقالات اللونية؛ جرّبي لوحة المفاتيح، واتجاه RTL، وملء الشاشة على شاشة الصف، ثم أعيدي الاختبار بميكروفون حقيقي. تفضيل النظام «تقليل الحركة» يوقف الحركات عمدًا؛ تظل الحالات والمعنى ظاهرين وتبقى الدموع ثابتة فقط أثناء البكاء في هذا الوضع.

## النشر

**GitHub Pages:** ارفعي مجلد `koala` كما هو إلى الفرع المنشور. عند استخدام موقع المستودع الحالي تصبح اللعبة تحت المسار `/koala/`، دون استبدال الموقع الموجود. يعتمد النشر الفعلي على إعدادات Pages الحالية؛ تم التحقق من نجاح النشر لهذا المستودع في سجل GitHub Pages؛ راجعي قسم اللعب من المتصفح أعلاه.

**Netlify:** اختاري مجلد `koala` مجلدَ النشر، واتركي أمر البناء فارغًا، أو اسحبي محتويات المجلد إلى النشر اليدوي. جميع المسارات نسبية. لا حاجة لخادم خلفي أو متغيرات بيئية. لا تنشري مجلد الاختبارات أو `prototype.html` إن لم ترغبي في إتاحتهما؛ لا تعتمد اللعبة عليهما.

## حدود بصرية وتقنية صريحة

هذه أصول ثنائية الأبعاد مولّدة خصيصًا بمظهر ثلاثي الأبعاد، وليست نموذجًا ثلاثي الأبعاد أو فيلمًا متصلاً بمفاصل وعظام. تتحرك الطبقات والدموع والنجوم والأذن وموضع مسح العين باستخدام CSS؛ يتغير التعبير بانتقالات بين لوحات متناسقة. قد يختلف موضع بعض تفاصيل الغرفة قليلًا أثناء الانتقال، وحركة الجسم تعبيرية محدودة وليست محاكاة فرو أو أطراف ثلاثية الأبعاد. لم تصل صورة المرجع المذكورة ضمن المرفقات؛ بُني الشكل على الوصف والنموذج HTML المتاح.

لا يمكن للمتصفح معرفة مصدر الضوضاء أو فصل أصوات الطالبات عن المراوح أو الأصوات الخارجية. النسبة تقريبية وتتأثر بموقع الميكروفون والجهاز. لا يُستخدم الصوت لتحديد الهوية أو إصدار حكم فردي. لا تتضمن اللعبة أصوات بكاء. يلزم اختبار بشري لميكروفون الصف ولمتصفحات Safari وFirefox ولمس الأجهزة الحقيقية؛ اختبارات البيئة الحالية على Chromium فقط.
